# 检测规则与证据边界

规则来自输入报告所描述的通用行为模式，由本项目重新实现；未复制厂商规则、PoC 或原报告 IOC。报告中存在信息缺省、重复以及版本范围不一致，不将未经独立核验的 CVE/版本信息直接作为确认依据。

| 规则 | 输入报告启发的模式 / 检测条件 | 证据边界 |
| --- | --- | --- |
| B001 | 招聘/文档钓鱼后 Office → Shell | 合法宏可能误报 |
| B002 | Web/数据库服务 → Shell | 不宣称特定漏洞被利用 |
| B003–B004 | Agent 扩展变更、未授权工具调用 | verified/authorized 须来自可信网关 |
| B005 | 非授权读取凭据/工作负载 token | 路径线索不等于内容已外泄 |
| B006 | KubePi SSO / Nacos 管理路径、未认证、成功状态 | 200 也可能是登录页；需业务审计确认 |
| B007 | 未授权建号/授权/SSO 变更 | 根据身份系统授权审计字段判断 |
| B008 | Jeecg 字典接口 filterSql 中 SQL 语法 | 仅可疑请求，不确认 SQL 注入 |
| B009 | 下载端点路径遍历 | 需核验响应、文件访问和业务上下文 |
| B010 | TradeDocAction / 上传路径出现脚本文件名 | 文件名需 WAF/应用提供，不能凭 URL 猜测 |
| B011 | 非批准计划任务/服务/cron/启动项 | 变更基线必须准确 |
| B012 | 文件名 Unicode 双向文字控制字符 | 需结合文件类型、签名和执行行为 |
| B013 | 非授权元数据地址访问 | 常见云 SDK 访问须放入业务基线 |
| B014 | Web 根目录脚本写入 | 核验部署流水线记录和文件内容 |
| B015 | 非批准 JDBC 目标变更 | 不从 Db2 版本直接推断漏洞 |
| B016 | 未授权远程管理/内网基础服务连接 | 基线不完整可能误报 |
| B017 | Sysmon 注册表启动项变更 | 常见合法安装程序也会写入 |
| B018 | 至少6个不同时间点连接，均值10–600秒、间隔CV≤0.15 | 监控/轮询可同样规律 |
| I001 | 有效情报精确匹配 | 共享IP、动态IP和撤销状态需复核 |
| C001 | 文档执行 → 有效 IOC 对端外联 | 同资产、15分钟内、有序；非进程级因果证明 |
| C002 | Web可疑请求/配置变更 → 服务执行/脚本落地 | 同上 |
| C003 | Agent异常 → 凭据读取/内网访问 | 同上 |
| C004 | 可疑执行 → 持久化配置 | 同上 |

所有规则标为 experimental。ATT&CK 标识为分析映射，不表示 MITRE 验证或特定攻击者归因。

风险分 = 最高线索分 + 不同阶段加分（最多16）+ 行为与情报共现15分，最高99。重复同一 IOC、重复日志、重复导入不增加阶段加分。输出包含计算分量。可按规则+资产设置有原因、有到期时间的抑制；不能把“内网 IP”整体当成可信身份。

响应计划须满足风险门槛、独立行为与 IOC、明确资产 IP 对端、启用响应、证据新鲜、非关键业务资产、非受保护地址。执行前还检查计划/授权有效期、策略摘要、目标主机与本地 hostname、TTL。发现暴露资产和文章搜索结果仅丰富研判上下文，不直接使处置可执行。

管理类通知用于理解岗位工作流，不是可检测的技术证据；未将其中个人、排班、联系方式等信息用于公开代码。每日情报统计数量不等于可从 PDF 提取的完整 IOC 数量；没有据此生成不存在的 IOC。

## v0.3.0 角色基线与行为链

新增 B101 内部远程服务访问偏离、B102 短时不同目标扇出、B103 身份授权组合偏离、B104 权限提升组合偏离，以及 C101 同账户权限变化后横向访问关联。它们不要求 IOC。原有规则继续工作；角色预期路径和精确限时例外只影响新模型，不掩盖既有命中。

基线在设计期审核并与登记资产角色绑定。遥测不足或审核过期会显示覆盖缺口，不把“没有告警”解释为安全。实现条件、ATT&CK 来源、数据契约和实验性边界见 [行为基线指南](BEHAVIOR_BASELINES.md)。
