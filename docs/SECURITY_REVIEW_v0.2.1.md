# Sentinel-ZT-CTTR v0.2.1 安全代码审查与修复报告

审查日期：2026-09-21。基线：已交付的 v0.2.0 代码包，与审查开始时的本地源码逐文件一致。基线 ZIP SHA256：`f94cc9d060ff56e60e889cfc1af578bbc7037b35d818b8bd50ccf00aceeb70dc`。

**结论：发现可复现的授权判断缺陷、输入处理与资源耗尽风险，以及影响证据完整性和界面可用性的 bug，已修复并交付 v0.2.1。** 本报告针对交付代码，不代表已经更新或验证 GitHub 远端当前分支，也不代表已对生产系统完成渗透测试。

## 审查范围与方法

人工检查 Python 核心、FastAPI 路由及中间件、React 导入与显示逻辑、Pi 子进程边界、CLI 响应签名和执行流程、Quake/知识库外部输入、云脉交接单和部署配置。使用合成数据复现问题，增加回归测试，运行依赖漏洞审计和本地 Chromium 界面检查。

重点检查身份与权限的信任来源、不可信数据处理、拒绝异常输入、最小权限、时效复核、数据完整性与资源预算。下表优先级是本项目修复顺序，不是 CVSS 评分；“可触发”不等于未经认证即可远程利用。

| --- | --- | --- | --- |

## 关键复现与回归证据

全部使用本地合成数据，没有向真实目标发送攻击或处置命令。

- **授权**：v0.2.0 的 `permissions[subject] = "read_sensitive"` 配合 `action = "read"` 返回 allow；修复后配置被拒绝。合法数组 `["read_sensitive"]` 对 `read` 返回 deny。NaN、无穷、负数、字符串和布尔风险值均被拒绝。
- **输入**：修复前空 IOC、`tlp: null` 和字符串 `analysis_window_seconds` 返回 500。回归包含 **135 组 IOC/策略字段变异**，修复后这些输入未产生 5xx；允许的输入仍正常处理。
- **时效**：模拟签名审批在 nftables 只读预检期间过期；回归确认仅发生 `check=True` 调用，没有发出实际变更调用。
- **前端**：Chromium 实际上传 `{}` IOC 文件，出现中文错误提示，关闭导入框后仍可查看证据并继续使用工作台；无页面脚本错误。
- **资源**：并发超过 2 个写任务返回 429；匿名 POST 不能占用受保护任务槽；超大请求和分析/报告展开超预算明确失败。

一次本地微基准用于验证算法修复，数字不作为应急响应效率或生产吞吐量承诺：

| 合成输入 | v0.2.0 | v0.2.1 | 正确性检查 |
| --- | ---: | ---: | --- |
| 含 3,000 组 `](` 的畸形 Markdown | 0.0511 秒 | 0.00037 秒 | 均未生成文章条目 |
| 2,000 条同资产日志、无法成立的时间配对 | 0.8669 秒 | 0.0484 秒 | 均生成 2,000 条基础 finding |

## 升级事项

1. 停止旧版工作台，备份私有工作目录、配置和签名密钥，使用 v0.2.1 完整代码目录替换应用源码及前端静态文件；保留私有数据在应用目录之外。
2. 使用原非特权服务账号安装更新后的 `requirements-web.txt`。检查数据目录归属和权限；POSIX 下要求目录 0700、访问令牌和 `cases.sqlite3` 为 0600 或更严格。发现宽权限时先核验再修正，不要通过 root 启动网页服务绕过错误。
3. 历史案例保留原结果，不会自动重新计算。重要调查需从原日志重新导入，再生成响应计划、审批或云脉交接单。没有上传策略的调查现在仅有空资产注册表，不再继承演练资产权限。
4. 事件上限由 100,000 调整为 10,000；完整预算在 `docs/DATA_CONTRACT.md`。超额调查按时间和资产范围拆分。达到 500 案例上限时归档整个工作目录，再新建私有工作目录。

## 保留的边界与未验证项

- 未发现本次已审代码路径中的网页直接封禁、Pi 签名/执行权限、SQL 字符串拼接注入或未转义日志 HTML 执行路径。此结论不等于证明不存在其他漏洞。
- 工作台仍使用共享 Bearer token。未实现个人 SSO、RBAC、租户隔离和独立双人审批；云脉网络接入不能替代应用内身份治理。
- 真实云脉租户、连接器、访问控制优先级、已有会话切断和审计 API 未联调。交接单仍为人工审核材料，不会自动下发策略。
- nftables 仅通过生成脚本和替身 runner 验证，未在真实内核执行封禁或回滚。生产上线前仍需隔离环境演练。
- 未提供 Quake 或模型凭证，未新增真实 Quake 查询/模型 API 验证。Windows ACL、长时压测和多进程部署未验证。
- 本地管理员仍可修改源码、策略和日志；HMAC 审计链需要外部保存头摘要才能检测完整替换或尾部截断。依赖审计只能反映本次版本在当时漏洞库中的结果。
