重跑核心与接口测试：

```bash
python -m pip install -r requirements-test.txt
python -m unittest discover -s tests -v
```

若未安装测试依赖，15 项 API 测试会跳过，不能据此报告接口已验证。

重跑 Pi 测试和前端构建：

```bash
cd agent
npm ci --ignore-scripts
npm test
cd ../web
npm ci --ignore-scripts
npm run build
```

浏览器人工复核：按 README 启动工作台，运行演练并展开证据；在资产发现中导入 `examples/quake-service.json`；知识库上传含 Markdown 链接的 README 后检索；在未配置模型时确认 Pi 分析按钮禁用；将浏览器宽度缩至 390px 检查布局。`console.png` 是合成演练的实际界面截图。

## 尚未验证

- **真实 nftables 封禁**：仅验证生成的命令、授权条件、模拟执行及回滚路径。未在真实内核网络命名空间运行；上线前按 RESPONSE.md 完成隔离演练。

- **检测准确率**：合成用例覆盖行为逻辑，不能用于声明生产检出率或误报率。文章收藏、未验证漏洞版本和单个 IOC 均不足以证明主机失陷。
- **GitHub 发布**：交付包含源码、构建产物、许可证与 CI；尚未创建远程仓库或执行公开推送。

## 数据与行为边界

公开交付仅包含通用规则、合成日志与示例情报，不包含用户上传的原始报告、人员名单、真实业务地址、凭证或文章正文。知识索引不会执行上游内容，Quake 发现不会自动授权资产，Pi 不能签署或执行响应。真实响应始终通过独立 CLI、短期授权和显式 `--live` 进入。
