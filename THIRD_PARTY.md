# Third-party components and references

Original code is MIT. Dependencies retain their own licenses; installing this repository does not relicense upstream packages, research papers, reports or linked articles.

| Component / reference | Purpose |
| --- | --- |
| [Pi Agent Core](https://github.com/earendil-works/pi/tree/main/packages/agent) | Optional stateful agent runtime, constrained tool execution; exact installed versions in agent/package-lock.json |
| [React](https://github.com/facebook/react) | UI runtime |
| [FastAPI](https://github.com/fastapi/fastapi) | Local API |
| [Vite](https://github.com/vitejs/vite) | Frontend build tooling |
| [Lucide](https://github.com/lucide-icons/lucide) | UI icons; ISC license |
| [360 Quake](https://quake.360.net/quake/) | Passive asset discovery; implementation based on the API documentation provided by the user |
| [360 Quake official CLI](https://github.com/360quake/quake_rs) | Cross-check of search, pagination and credential conventions; no upstream code copied |
| [izj007/wechat](https://github.com/izj007/wechat) | Optional article title/link discovery; no article bodies or PoC programs redistributed |
| [NIST SP 800-207](https://csrc.nist.gov/pubs/sp/800/207/final) | Conceptual identity/device/resource checks; no claim of conformance certification |
| [STIX 2.1](https://docs.oasis-open.org/cti/stix/v2.1/os/stix-v2.1-os.html) | Limited Indicator import; not a complete STIX/TAXII implementation |
| [nftables manual](https://netfilter.org/projects/nftables/manpage.html) | Dedicated tables, input/output chains and expiring sets |
| [Sysmon documentation](https://learn.microsoft.com/en-us/sysinternals/downloads/sysmon) | Event field semantics |
| [Suricata EVE documentation](https://docs.suricata.io/en/latest/output/eve/eve-json-output.html) | Network telemetry adapter |

Public packages intentionally contain no original operational reports, personal rosters, private IOCs, customer topology or screenshots from those reports. Original research material was used to identify generic defensive behavior categories. Supplied examples use documentation address ranges and reserved example domains.
